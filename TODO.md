# After cloning: things to re-download, re-create and re-run

The repository contains only source code, tests, configuration templates and documentation.
Everything below is deliberately **not** committed because it can be regenerated. Do these steps
in order on a fresh clone.

## 1. Re-download dependencies

- [ ] **Backend Python packages** (creates `backend/.venv/`, about 1 GB with OpenCV and ChromaDB)
  ```bash
  cd backend
  python -m venv .venv
  .venv\Scripts\activate            # macOS/Linux: source .venv/bin/activate
  pip install -r requirements.lock.txt   # exact versions that passed the tests
  # or: pip install -r requirements.txt  # latest compatible versions
  ```
- [ ] **Frontend Node packages** (creates `frontend/node_modules/`)
  ```bash
  cd frontend
  npm install
  ```

## 2. Re-create secret and config files (never committed)

- [ ] `backend/.env`  copy from `backend/.env.example`, then fill in:
  - `GEMINI_API_KEY`  from https://aistudio.google.com/app/apikey
  - `MONGODB_URI`     local `mongodb://localhost:27017` or your Atlas string
  - `JWT_SECRET`      `python -c "import secrets; print(secrets.token_urlsafe(48))"`
  - `TESSERACT_CMD`   only if tesseract is not on PATH
- [ ] `frontend/.env.local`  copy from `frontend/.env.local.example` (default value is fine locally)

## 3. Install system software (not part of the repo)

- [ ] **MongoDB** 6+  local server or free Atlas M0 cluster
- [ ] **Tesseract OCR** 5  only needed for scanned PDFs / images
  - Windows: https://github.com/UB-Mannheim/tesseract/wiki
  - macOS: `brew install tesseract`
  - Debian/Ubuntu: `sudo apt install tesseract-ocr`
- [ ] Python 3.11+ and Node.js 20+

## 4. Runtime folders (created automatically on first start, kept empty in git)

- `backend/uploads/`   uploaded report files. Regenerated as users upload.
- `backend/chroma_db/` ChromaDB vectors. Rebuilt automatically from MongoDB text the first time a
  question is asked on a report, so deleting it is safe.
- `frontend/.next/`    Next.js build output. Regenerated by `npm run build` or `npm run dev`.

## 5. Re-run to verify the clone works

- [ ] Backend tests (no MongoDB, Gemini key or Tesseract needed)
  ```bash
  cd backend && .venv\Scripts\activate && pytest
  # expected: 55 passed
  ```
- [ ] Frontend type-check and build
  ```bash
  cd frontend && npm run build
  ```

## 6. Start the app

```bash
# terminal 1  (skip if using Atlas)
mongod --dbpath <your-data-dir>

# terminal 2
cd backend && .venv\Scripts\activate && uvicorn app.main:app --reload --port 8000

# terminal 3
cd frontend && npm run dev
```

Open http://localhost:3000. Full details are in README.md section 4.
